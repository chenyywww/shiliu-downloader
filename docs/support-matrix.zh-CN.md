## 如何理解验证

- **独立安装实测**：从公开仓库重新获取源码，在新的 Python 依赖目录中实际运行。
- **历史成功记录**：本项目已有样本成功，但不是当前版本在全部网站重新测试的结果。
- **用户反馈**：使用者报告成功，不等于维护者完成相同条件的独立验收。
- **自动测试**：用本地生成媒体和虚构作品编号验证代码行为，不涉及真实用户账号。

解析、下载、短片段检查、完整解码和跨网络下载是不同的验证范围。站点或账号权限变化后，历史成功也可能失效。公开文档不包含私人测试作品链接。
