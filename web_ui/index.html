本机设置

登录与辅助

大多数公开作品先匿名解析。需要时，可在工具独立窗口中手动登录并保存。

抖音登录

匿名解析失败后，自动尝试你主动保存的会话。

X 登录

先保存会话，再勾选下载选项里的“允许 X 登录后备”。

YouTube 登录

在自己的常用浏览器登录，再导入本人会话。下载时勾选“允许 YouTube 登录后备”。

YouTube 会话导入与账号切换
  1. 在常用浏览器登录 YouTube，完成网站要求的确认，并确认目标视频能播放。
  2. 按官方说明导出 youtube.com 的 Cookie，保存为 Netscape 格式的 TXT 文件。
  3. 点击下方“导入 Cookie 文件”；随后勾选“允许 YouTube 登录后备”并重试。

仅保留 youtube.com 的会话，提交后在本机加密保存。Cookie 文件只通过本机网页导入。

查看 yt-dlp 官方导出说明 ↗

独立窗口是可选方式；Google 可能拒绝此类浏览器。

独立登录窗口会加入任务队列，请自行完成登录并点击工具页里的保存按钮。YouTube Cookie 导入可直接在本页完成。

会话属于当前使用者；这里只有本机保存记录，不代表会话仍有效。工具不读取个人 Chrome 的账号资料。向他人分发程序时，请使用发布包，排除 .auth、.web 和日志。
